গল্পকথা — ওয়েবসাইট প্রোটোটাইপ

চালানোর নিয়ম:
1. index.html এবং admin.html একই ফোল্ডারে রাখুন।
2. index.html খুললে পাঠকের ওয়েবসাইট দেখবেন।
3. admin.html খুলে প্রথমবারের পাসওয়ার্ড 213764859 দিয়ে লগইন করুন।
4. গল্পের নাম, লেখক, ধরন, পর্ব ও লেখা দিয়ে প্রকাশ করুন।
5. পাসওয়ার্ড পরিবর্তন ড্যাশবোর্ডের নিচে আছে।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এটি pure HTML/CSS/JavaScript প্রোটোটাইপ। গল্প, রিঅ্যাকশন ও মন্তব্য একই ব্রাউজারের Local Storage-এ থাকে।
- অ্যাডমিনের প্রকাশিত গল্প অন্য ব্যবহারকারীর ডিভাইসে নিজে থেকে যাবে না। সবার জন্য সত্যিকারের অনলাইন প্রকাশে backend/API এবং database (যেমন Firebase/Supabase) লাগবে।
- এই ফ্রন্টএন্ডে রাখা পাসওয়ার্ড নিরাপদ authentication নয়; browser storage/JS থেকে দেখা বা বদলানো সম্ভব। পাবলিক সাইটে সার্ভার-সাইড authentication ও access rules ব্যবহার করুন।
- বাহ্যিক Google Fonts লোড হলে সুন্দর বাংলা ফন্ট দেখাবে; অফলাইনে fallback font ব্যবহৃত হবে।
